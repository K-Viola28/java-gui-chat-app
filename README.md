# java-gui-chat-app
A simple Java Swing chat application using OOP concepts and database storage.


WHAT TO NOTE.
Deletion of messages has not yet been incorporated yet. Any changes made that affect the database can only be changed by the admin.
To chat, the two users must be on the same chat server.
