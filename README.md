# java-gui-chat-app
A simple Java Swing chat application using OOP concepts and database storage.


<p>WHAT TO NOTE.</p>
<p>Deletion of messages has not yet been incorporated yet.</p>
<p>Any changes made that affect the database can only be changed by the admin.</p>
<p>To chat, the two users must be on the same chat server.</p>
